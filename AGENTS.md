# Agent working rules

Read README.md, INSTALL.md, and AGENT_SETUP.md before setup or scene work. Inspect local changes. Preserve student work, existing GUIDs, original third-party assets, and Camera/Keys controls. Root README and current source supersede historical control descriptions.

Commit required Assets with their metadata, Packages, ProjectSettings, authored tracking source/tests, scripts, and docs. Exclude environments, downloads/models, caches, IDE files, logs, recordings, secrets, and local backup scenes. Review staged names/sizes before pushing; never force-add Elephant or broadly stage ignored files.

Use saved copies for integration. Do not regenerate metadata or run scene builders against the delivered kart scene. Report Python/static, Unity, and real camera/Game-view checks separately. Synthetic packets do not establish physical validation.
